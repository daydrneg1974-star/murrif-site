# murrif.ru

Личная визитка Рифката Муравлева. Статический сайт без сборки, базы данных и внешних CDN.

## Размещение

В публичную папку хостинга нужно загрузить только:

- `index.html`, `privacy.html`, `consent.html`;
- `photo-fade.webp`, `photo-square.webp`, `og-image.jpg`;
- папку `fonts/` вместе с файлами лицензий.

Главная страница должна находиться непосредственно в корне публичной папки, без вложенной папки архива. Репозиторий `.git`, архивы, документацию и тесты публиковать на сайте не нужно.

Хостинг: SpaceWeb. Временный адрес: http://murrif.ru.swtest.ru/.

Состояние домена и проверок при восстановлении: [отчёт от 21 ноября 2026](docs/reports/restore-2026-11-21.md).

## Форма заявки

Форма открывает почтовое приложение через `mailto:`. Посетитель самостоятельно отправляет подготовленное письмо. Серверной отправки писем нет. После открытия письма введённые данные сохраняются в форме; без JavaScript доступны прямые контакты.

Проверка обработчика формы без установки зависимостей:

```sh
node tests/contact-form.test.cjs
```

Эта проверка не подтверждает доставку письма, внешний вид на телефоне или наличие почтового приложения у посетителя.
