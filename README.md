# murrif.ru

Личная визитка Рифката Муравлева. Статический сайт без сборки, базы данных и внешних CDN.

## Размещение

В публичную папку хостинга нужно загрузить только:

- `index.html`, `privacy.html`, `consent.html`;
- `robots.txt`, `sitemap.xml`;
- `photo-fade.webp`, `photo-square.webp`, `og-image.jpg`;
- папку `fonts/` вместе с файлами лицензий.

Для SpaceWeb также нужен `.htaccess` из репозитория: он перенаправляет HTTP на HTTPS. Размещать его следует после установки действующего сертификата для домена.

Главная страница должна находиться непосредственно в корне публичной папки, без вложенной папки архива. Репозиторий `.git`, архивы, документацию и тесты публиковать на сайте не нужно.

Хостинг: SpaceWeb. Основной адрес: https://murrif.ru/. `https://www.murrif.ru/` также открывает сайт. HTTP перенаправляется на HTTPS кодом 301 с сохранением пути и параметров.

Установлен бесплатный Let's Encrypt. Хостинг находится в SpaceWeb; управление DNS пока остаётся в Beget, почтовые записи сохранены.

Состояние домена и проверок при восстановлении: [отчёт от 21 ноября 2026](docs/reports/restore-2026-11-21.md).

## Индексация

`robots.txt` разрешает обход всем роботам и указывает на `https://murrif.ru/sitemap.xml`.
Карта содержит три существующие страницы с их каноническими HTTPS-адресами без `www`.
При добавлении или удалении страниц обновляйте карту. Не добавляйте в неё ресурсы,
якоря, дубли `/index.html` или технический домен хостинга. Необязательные даты
`lastmod` не указаны, чтобы не сообщать роботам неподтверждённое время изменения.

Смена хостинга при сохранении домена сама по себе не требует заявки на переезд в
Яндекс Вебмастере. Добавление Sitemap и переобход не гарантируют включение в поиск.

Публикация файлов проверена; действия в Вебмастере ожидают входа пользователя.
Подробности и доказательства: [отчёт об индексации](docs/reports/indexing-2026-11-21.md).

## Форма заявки

Форма открывает почтовое приложение через `mailto:`. Посетитель самостоятельно отправляет подготовленное письмо. Серверной отправки писем нет. После открытия письма введённые данные сохраняются в форме; без JavaScript доступны прямые контакты.

Проверка обработчика формы без установки зависимостей:

```sh
node tests/contact-form.test.cjs
```

Эта проверка не подтверждает доставку письма, внешний вид на телефоне или наличие почтового приложения у посетителя.
