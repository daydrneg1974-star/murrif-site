# Публикация утверждённого графитового фона

21 ноября 2026 владелец утвердил фон `#383840` и поручил опубликовать его на SpaceWeb. Сайт: https://murrif.ru/.

## Версия и резервные копии

- Утверждённый дизайн: `c7c168913dbf789fec05a7463e6ff22cbdf1b708`, ветка `design/light-background`.
- Предыдущий GitHub main: `560a90ba38d1b3b2641f58343f6a3d789cdfb459`.
- Резервная ветка: `backup/dark-before-light-2026-11-21`, на том же предыдущем коммите.
- Перед публикацией HTTPS-байты всех трёх HTML-страниц совпали с предыдущим main и резервной веткой.
- Через файловый менеджер SpaceWeb создана полная копия `public_html` вне публичного корня: `/home/p/pridomahru/murrif_ru/backup-dark-before-graphite-2026-11-21`. В интерфейсе подтверждены папки, три HTML, изображения, `.htaccess`, robots.txt и sitemap.xml.

## Изменения на хостинге

Заменены только `index.html`, `privacy.html` и `consent.html` в `/home/p/pridomahru/murrif_ru/public_html`. Фон и связанные поверхности соответствуют утверждённому варианту. Тексты, фотографии, размеры, кнопки, ссылки и JavaScript сохранены.

Текстовый редактор SpaceWeb удалил один конечный LF в каждом HTML. Повторная загрузка подтвердила, что это единственное отличие от утверждённого исходника; исходники в GitHub приведены к опубликованным байтам. Изменение не влияет на отображение и выполнение HTML.

Ограничения индексации из приватной копии для просмотра не переносились: на основном сайте нет meta noindex, robots.txt по-прежнему разрешает обход. `.htaccess`, DNS, сертификат, изображения, шрифты, Sitemap и соседние проекты не менялись.

## Откат

Для возврата прежнего фона достаточно восстановить три HTML из резервной папки SpaceWeb в `public_html`; остальные файлы и настройки менять не требуется. Исходники прежней версии также доступны в резервной ветке GitHub. Откат в GitHub следует оформлять отдельным коммитом, сохраняя историю.
