## Что осталось

На момент проверки публичные DNS возвращали:

- A `murrif.ru`: `87.236.16.20`;
- NS: серверы Beget;
- MX: `mx1.beget.com`, `mx2.beget.com`;
- AAAA: отсутствует.

Целевой IP сайта SpaceWeb: `77.222.40.70`. Панель SpaceWeb не может изменить текущую внешнюю DNS-зону.

Для подключения основного адреса нужен доступ к текущему управлению доменом/DNS. Перед изменениями сохранить всю существующую зону. Можно переключить только веб-записи A основного домена и `www`, сохранив почтовые записи. Если переносить DNS на SpaceWeb целиком, сначала перенести необходимые MX, TXT и остальные используемые записи.

После обновления DNS выпустить бесплатный Let's Encrypt для `murrif.ru` и `www`, проверить HTTPS, затем включить перенаправление HTTP → HTTPS и завершить проверку на узком экране. Сертификат пока не заказывался: проверка HTTP требует A-запись SpaceWeb, проверка DNS — DNS-серверы SpaceWeb.

Полное восстановление основного адреса не объявлено завершённым.
