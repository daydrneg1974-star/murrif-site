# Восстановление визитки на SpaceWeb

Статус: сайт восстановлен и открыт по https://murrif.ru/. HTTPS, перенаправление и основные сценарии проверены. Физический телефон и доставка настоящих писем не проверялись.

## Источник и изменения

- Исходная версия: `04e1e70863fb9eb525c05ae3ed77cee610ac10b1`.
- Версия HTML и ресурсов на сервере: `b7f8b7e354d9520f6068ee36307ec2d7261022bd`.
- Сохранены исходный дизайн, фотографии, тексты, локальные шрифты и документы.
- В исходниках уже были исправлены нумерация шагов, описание опыта HoReCa/госзакупок, удалены услуги мобильной разработки и сокращён пункт формы до «Нужна консультация».
- Исправлена форма: после подготовки письма она не стирает введённые данные; без JavaScript кнопка отключена, чтобы предотвратить стандартную GET-отправку полей в URL; добавлено пояснение о почтовом приложении и запасных контактах.
- Добавлен `.htaccess` с перенаправлением HTTP → HTTPS для конфигурации SpaceWeb. Путь и параметры запроса сохраняются.

## HTTPS

В SpaceWeb установлен бесплатный Let's Encrypt для `murrif.ru`: без выделенного IP, без Wildcard, подтверждение по HTTP. В панели статус «Установлен», следующая дата выпуска указана как 2027-02-19. Повторные заказы не создавались; другие сертификаты не изменялись.

И `https://murrif.ru/`, и `https://www.murrif.ru/` открылись в подключённом браузере без предупреждений. Проверки HTTPS выполнялись без отключения проверки сертификата. SAN сертификата отдельно не выгружался.

Директивы перенаправления основаны на [инструкции SpaceWeb](https://help.sweb.ru/nastrojka-sajta-dlya-raboty-po-https_198.html). `.htaccess` добавлен после успешного открытия HTTPS. Проверены 301 для обоих HTTP-имён, документа и запроса с параметром; целевые HTTPS-страницы возвращают 200, циклов нет.

## Практические ограничения

- Форма использует `mailto:`: посетитель отправляет подготовленное письмо из своего почтового приложения. Серверной отправки нет; реальные письма при проверке не отправлялись.
- Проверки 320×800 и 360×800 выполнены изменением размеров окна браузера, не на физическом телефоне.
- При искусственно узком окне 272 CSS px текст пункта формы обрезается. Этот режим не отмечен как пройденный; на проверенных 320 px текст читается полностью.
- Первоначальная проверка HTTP в браузерах была ограничена `ERR_BLOCKED_BY_CLIENT` / `ERR_HTTP2_PROTOCOL_ERROR`. После выпуска сертификата проверка опубликованного сайта по HTTPS выполнена успешно.
- Управление DNS и прежние почтовые записи остаются в Beget. Для полного отказа от его DNS потребуется отдельно перенести зону без потери почтовых записей.
