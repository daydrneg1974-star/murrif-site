# T01 — результат реализации

Это исторический снимок первой реализации до независимой проверки. В первом круге найден пропущенный случай светлой подложки под шапкой; актуальное исправление, расчёты и ограничения описаны в [round2-implementation-notes.md](round2-implementation-notes.md). Первоначальные доказательства ниже сохранены.

Исправления готовы к независимой и браузерной проверке; 22 автоматические проверки проходят. Изменения не закоммичены и не опубликованы исполнителем.

## Точные изменения

- `index.html`, `privacy.html`, `consent.html`: `--ink-soft` изменён с `#a1a1aa` на `#ceced6`, `--ink-muted` — с `#8b8b95` на `#c0c0cc`.
- `index.html`: подсказки полей используют `--ink-muted` с `opacity: 1`. Фон `#383840`, поверхности, градиенты, изображения, размеры и расположение сохранены.
- `index.html`: Escape закрывает открытое меню; фокус возвращается на кнопку, только если находился внутри меню. Escape с фокусом вне меню не перемещает его. Обработчик выбора ссылки не изменён.
- `index.html`: «Технически сделать сайт может многие» исправлено на «Технически сделать сайт могут многие». Остальные тексты, услуги и обработчик формы сохранены побайтово.
- `tests/contact-form.test.cjs`: каждый случай создаёт отдельные поля, обработчик, статус и историю переходов. Вместо пустой функции используется настоящий отменяемый `Event`, отправляемый через `EventTarget`: проверяются `defaultPrevented` и результат `dispatchEvent`. На всех отправках проверяется сохранность пяти полей. Добавлены неполные и пробельные значения, пустое сообщение, повтор, исправление согласия и точное восстановление кодированных значений из mailto. Проверка настроенного адресата сохранена; смоделированные письма и все введённые контакты используют `example.invalid`.
- `tests/mobile-menu.test.cjs`: пять случаев для Escape, фокуса, других клавиш и сохранения обычной навигации по ссылке.
- `tests/contrast.test.cjs`: три проверки страниц, 64 сочетания текста и поверхностей из текущего CSS с учётом прозрачности и крайних цветов градиентов. Зависимостей и фреймворков не добавлено.
- `README.md`: общая команда `node --test tests/*.test.cjs`, требуемый Node.js 20+, состав и ограничения проверок.
- `.gitignore`: только внутри `docs/tasks/artifacts/` разрешены текстовые доказательства, остальные типы исключены. Изображения в `docs/reports/` не затронуты.

## Ограничения и следующий шаг

Тесты формы и меню выполняют извлечённые обработчики с поддельным DOM. Числа CSS не подтверждают итоговую отрисовку, динамический фон под полупрозрачной шапкой или поведение всех браузеров. Исполнитель не занимал браузер: полный запуск страницы, меню, квиз, форма, отсутствие перехода с полями в URL, размеры и состояния экранов проверяются оркестратором отдельно до и после публикации. Настоящих писем, обращений к почтовому клиенту или внешних сетевых вызовов в тестах нет. Доставка письма и физические мобильные устройства этим прогоном не проверены.

Новых баг-репортов не заведено: автоматические проверки зелёные; известные недостатки исправлены в рамках T01. Статус задачи остаётся `in_progress`, критерии приёмки не изменены.
