## Граница проверки

В устойчивом состоянии обычная шапка `.72` находится над основным фоном; при прокрутке более 8 px включается `.86`. Проверены оба состояния и их hover/active. Дополнительно проверена обычная шапка над максимально белой подложкой без hover/active.

Для теоретического сочетания `.72` + абсолютно белая подложка + белая подложка hover/active даже белый текст даёт лишь 4.1271/4.0495:1. Одной заменой цвета текста гарантировать 4.5:1 для этого сочетания нельзя. Оно не заявляется проверенным устойчивым состоянием; крайние кадры перехода не покрываются гарантией. Поверхности сохранены по согласованному ограничению, полной сертификации WCAG нет. Браузерный повтор найденного сценария `scrollY=600` и независимый вывод по C1 выполняются отдельно оркестратором и проверяющим.
