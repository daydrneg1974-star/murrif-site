# T01 — независимая проверка, круг 1

**Вердикт: ПРОВАЛ.** Критерий контраста C1 не выполнен для подписи полупрозрачной шапки при прокрутке. C2 и C3 доказаны в указанных ниже пределах.

| Критерий | Автоматическая проверка | Наблюдаемый результат | Итог |
|---|---|---|---|
| C1: контраст и сохранность страницы | Исходные 64 цветовые пары проходят. Новая регрессия шапки в `tests/contrast.test.cjs` падает на трёх HTML. Сравнение с базой подтверждает сохранность фона, прочей CSS-компоновки, разметки и 12 ресурсов. | При ширине контента 1440 CSS px и scrollY=600 белая кнопка hero перекрывается шапкой. После окончания перехода computedStyle шапки — rgba(64,64,73,.86), подписи — RGB(192,192,204). По 15 пустым участкам её line box в JPEG — приблизительно 4.10–4.49:1. | **ПРОВАЛ** |
| C2: Escape и контакты | Пять тестов меню проходят. | Фокус: ссылка → Escape → burger; меню закрыто. Escape в name при закрытом меню не перемещает фокус. Клик «Контакты» даёт #contacts и закрывает меню. | Доказан |

Регрессия шапки использует белую подложку как консервативную верхнюю границу для сохранённой полупрозрачности. Это отдельное расчётное доказательство, а не попытка выдать его за пиксельное измерение страницы. Уровень 4.5:1 не снижался.

Новые отрицательные тесты формы проверяют отзыв согласия после подготовки черновика и изменение данных между попытками, включая промежуточное имя из Unicode-пробелов. Предыдущее успешное действие не обходит валидацию и не приводит к повторному использованию старых данных.

Доказательства: [сохранность исходников](verifier-source-proof.json), [общий прогон до регрессии шапки](verifier-tests.log), [мутация](verifier-mutation.json), [падающая регрессия шапки](verifier-header-regression-before.log), [растровое измерение](verifier-header-pixel-evidence.json), [геометрия и итоговый CSS](preview-header-underlay-settled.json), [сырые UI-наблюдения](browser-preview-observations.json), [их оценка](verifier-browser-assessment.json).

Ограничения: Browser plugin не дал тестировщику доступ к исходному браузерному контексту. Действия по выбранным им сценариям выполнил оркестратор; тестировщик самостоятельно оценил JSON и локальные снимки. Поэтому это не независимое выполнение UI тестировщиком. JPEG-оценки приблизительны, исходные изображения не изменялись. Точное значение contact скрыто инструментом: сохранность всех пяти полей подтверждена изолированными тестами, без настоящего mailto или отправки писем. Доставка писем, физические телефоны, другие браузерные движки и полное WCAG-соответствие не проверялись.

Тестировщик не открывал вкладку и не менял viewport. Браузер остаётся у оркестратора. Задача остаётся `in_progress`, `verify_attempts` увеличен до 1. Нужен узкий пересмотр цветов текста шапки без изменения утверждённых поверхностей, затем второй круг.
